# Handoff: r-aizawa Blog — ルーズリーフ刷新（v2）

## Overview

`raizawa-blog`（HonoX + Cloudflare Workers + Tailwind CSS 4, SSG）のデザイン刷新 第2弾。
前回の「机の上に置いた1080pxの紙」（`design_handoff_paper_blog/`）を全面的に改め、**画面全体を1枚のルーズリーフにする**。

コンセプト：**「用紙にボールペンで雑にまとめている」**。時間をかけて組んだ紙面ではなく、メモの延長。

- 紙面＝ビューポート。「机」の余白は無くす
- 写真は白フチ台紙に貼らない。**テープで直貼り**
- 整列より密度。取消線・書き足し・矢印・欄外の独り言が混ざる
- 行はルーズリーフの罫線に乗る（配置は几帳面にしない）

## About the Design Files

`新デザイン案 v2.dc.html` は **HTMLで作ったデザインリファレンス**（プロトタイプ）です。そのまま製品コードにせず、既存の HonoX + Hono/JSX + Tailwind CSS 4 の環境・パターン（`app/components/*.tsx`、`app/style.css`）で**作り直してください**。インラインスタイルは「値の出典」です。

ファイル内は上から新しい提案です。**確定案は 3a（一覧）/ 4a（記事詳細）/ 5a（検索）/ 5c（自己紹介）/ 5d（遷移）**。TURN 1〜2 の他の案（1a〜2c）は不採用のアーカイブ。

## Fidelity

**High-fidelity**。色・タイポ・罫線・囲み・矢印の形まで確定。手書き線の path 座標は「そういう形」の見本（Rough.js で描くか、path 流用かは実装で選択）。

## 前回ハンドオフとの関係

`design_handoff_paper_blog/README.md` の以下は**そのまま有効**：

- Design Tokens（色・タイポグラフィ・シャドウ・Google Fonts）

### 見出し欄（赤線の左）= 1ページ1役割

- **一覧・検索など**：サイトの目次＝ナビ（記事 / 写真 / タグ / 検索 / 自己紹介、日本語）。現在地だけエンジの手書き楕円囲み。他はホバーで translateX(3px)
- **記事詳細**：**この記事の目次だけ**（「目次」ラベル + 節。現在地にエンジ下線＝スクロールスパイ、sticky）。メタ情報は置かない
- 余計なものを足さない（“一箇所には一つの役割” がオーナーの明示要望）

### 写真（テープ直貼り）

- 白フチなし。`box-shadow: 0 3〜4px 9〜11px rgba(43,39,33,.28)` + #grain（opacity .4, multiply）
- マスキングテープ：`rgba(235,226,196,.78)`、約 50〜66×18px、`box-shadow 0 1px 2px rgba(43,39,33,.2)`、±2〜6deg 回転。上辺2箇所 or 上1＋下1
- 本体は ±1.6〜2.8deg 回転、本文カラムからわざと少しはみ出す
- キャプションは写真の下にペン書き（Klee One 13.5px、微回転）

## Screens

### 3a 記事一覧 `/posts`

- 一覧＝「書き足していく索引」。1行 = `日付(13.5px #7b7566, 幅64px) | タイトル(Klee One 600 17px、最新のみ19px) | #タグ / 写真n枚 | 注記`
- 注記の種類（実データでは frontmatter やビルドで制御、乱発しない）：エンジの走り書き（「← 写真12枚、まだ半分しか貼ってない」）、取消線での書き直し（旧タイトルに `line-through` 相当の手書き線 → 隣に新タイトル）、深緑の矢印注記、黄土ハイライト
- 写真は右余白に3枚程度テープ貼り、ペンのキャプション + 「↑ 7/28の。」のような参照
- ページ送り：「つづきは次の紙 →（2枚目 / 27枚）」のペン書き
- ヘッダー右に `8/1 現在 133本 ・ page 1 / 27`

### 4a 記事詳細 `/posts/:slug`

- h1：Klee One 600 34px / line-height 68px（罫線2行分）、`filter:url(#ink)`
- メタ行（h1直下）：`7/28 ・ [しゅみ囲み] ・ 写真12枚 ・ 7/30 直した`（13px #7b7566）
- 節見出し：エンジの短いチェック風ストローク + Klee One 600 21px
- 本文中の書き込み：エンジ下線・黄土ハイライト 各1回/段落まで
- 写真は本文列から左に -14px はみ出し（rotate -1.8deg）、右余白に目次外の写真＋独り言（「※ ホテルの窓の話を先に書くべきだった。次に直す。」）
- コードブロック＝**印刷して貼った紙**：`#fdfcf7`、紙目 opacity .4、rotate -.5deg、紙束の影、上辺テープ2箇所、ファイル名行は `1px dashed rgba(43,39,33,.22)`、`copy` はエンジ
- **prev / next**：紙の左右いっぱいに伸びる**手書きの長い矢印**（エンジ、二度書き、矢じりは開いたV）。ラベルは説明なしで**記事タイトルのみ**（Klee One 600 17px、エンジ、`filter:url(#ink)`）。ホバーで矢印方向へ4px
- ヘッダー右：`6 min read` + 読了バー（鉛筆線 `#a99f88` 1px の上をエンジ 1.7px が伸びる）

### 5a 検索 `/search`

- 入力欄は**囲まない**。テキスト + エンジのカーソル（2×22px）の下に**ボールペンの速い二度書き下線**（濃1.6 + 薄1.4 + 書き始めの短い重ね）。実装は **Rough Notation の `underline`** を使うと同じ手になる（※プレビューでは絶対配置の都合で自前SVG。実装では入力欄の親要素基準で安定する）
- 右端に `3 results`（EB Garamond）
- 入力欄の下線から**1件目の結果へ縦に降りる手書き矢印**（深緑、内側へ曲がって矢じりが結果を指す）
- 余白に説明メモ：`検索（search ・ pagefind）。書けばすぐ出る`（深緑 13.5px、微回転）
- 結果：`日付 | タイトル(600 18px)`＋抜粋（14px #7b7566、字下げ80px）。**ヒット語は黄土ハイライト**：`linear-gradient(104deg, transparent 2%, rgba(200,149,47,.38) 6%, rgba(200,149,47,.34) 94%, transparent 98%)`
- Pagefind は JS API（`pagefind.search()`）で自前マークアップに流し込む

### 5c 自己紹介 `/about`

- 本文は罫線に乗せて左カラム、h1「相沢と申します」（30px, #ink）
- 右余白：本人写真（テープ貼り、rotate -1.6deg、キャプション「自分。だいたいこの角度」）→ elsewhere（github / zenn / x、`↗` はエンジ）→ 右下に Parisienne の署名
- note の手書き枠（このページ唯一の囲み）：**横長比率で描いた path**を使う（小さい path を引き伸ばすと線が太る。プレビューの viewBox="0 0 640 72" 版を流用）

### 6a ギャラリー記事 `/photos/:month`

- 同じルーズリーフ。見出し欄はサイト目次（現在地＝写真）
- グリッド：3カラム / auto-rows 190px / gap 34×30px。1枚目 `span 2×2`、4枚目横長 `span 2`。各写真テープ貼り・±1〜2°回転、ペンのキャプションは2枚だけ
- 下部に操作ヒント（←→の矢印も手書きSVG）

### 6b ライトボックス

- メタファ：**写真を紙から剥がして手に取る**。拡大中の写真にテープは付けない
- 背景：元ページを blur(3px) で残し `rgba(28,32,26,.6)` で沈める
- 写真：`0 30px 70px rgba(0,0,0,.5)`、微回転 .6deg。下にキャプション（紙色 #f6f1e4）＋ `3 / 9`（EB Garamond）
- ←→・✕ はすべて手書きの白線（✕は手書きの円囲い、タップ領域44px）。`←` `→` `Esc` キー対応、view-transition で開閉

### 6c OGP 1200×630（自動生成）

- ルーズリーフをそのまま切り取る：罫線（40pxピッチ）・赤線（left:130px）・綴じ穴×2・手書きヘッダー線
- 左：カテゴリ囲み＋写真枚数 → タイトル（Klee One 600 / 44px / line-height 80px, #ink）→ `r-aizawa.com` ＋ Parisienne 署名
- 右：cover をテープ貼り（rotate 2deg）＋ペンのキャプション。cover なしは左カラムを中央に広げる
- 生成は Satori + resvg（フォントサブセット埋め込み）

### 6d / 6e / 6f モバイル 390px

- 赤線は left:44px、罫線ピッチ 33px、見出し欄は畳む（ナビはメニューへ）
- ハンバーガー＝手書きの揺れた3本線（44×44）。閉じる✕も手書き
- 一覧（6d）：カバー1枚（テープ貼り）＋「タイトル／日付・カテゴリ」の2行リスト。各行 min-height 44px
- 記事（6e）：目次は本文の上の折りたたみ（囲まず「目次 ▾」＋薄線）。読了バーはヘッダー内の鉛筆線。prev/next は手書き矢印の縮小版（タイトルのみ・エンジ・#ink）

### 5d ページ遷移

- **次のルーズリーフが右から差し込まれて上に重なる**（下の紙は scale(.985) に沈む）。`.55s cubic-bezier(.2,.8,.2,1)`

| 手書き注釈             | **Rough Notation**（underline / strike / highlight）。`IntersectionObserver` で見えたとき一度だけ show()。SSG の静的部分は同梱の path 流用でも可 |

## 決定事項メモ（今回の追加分）

1. 紙面＝画面。机の余白は作らない
2. 写真は白フチ台紙に貼らない。テープ直貼り＋ペンのキャプション
3. 見出し欄（赤線の左）は1ページ1役割。記事ページでは目次のみ
4. 入力欄・強調は囲むより**下線**。囲みは「現在地の楕円」「カテゴリ」「note」だけ
5. 矢印は説明の向きに引く（抽象→具体、入力→結果）
6. prev/next は紙幅いっぱいの手書き矢印＋タイトルのみ（エンジ、#ink）
7. 横長の手書き枠は横長の viewBox で（線幅を太らせない）
8. タグ・カテゴリの「正の字」タリー案は不採用
9. **遷移・ナビの矢印は全て手書きSVG**。文字の「→」「↗」グリフは使わない（ページ送り・elsewhere・操作ヒント含む）
10. ライトボックス＝写真を剥がして手に取る。拡大中はテープなし、背後は元ページを暗く沈める
